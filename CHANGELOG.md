# Changelog

## v1.3.0 — 2026-11-19
- Every mode now asks: Practice or Assessment. Each mode has a 16-question scored assessment; Mode 5 is the 32-question Full Test.
- One Band Ninja Dojo link covers all five assessments; each can be turned in once with it (the banner counts how many are left).

## v1.2.0 — 2026-11-19
- New Mode 5: Key Signature Test. 32 questions across all four skills, no hints until the end, then a review of every miss.
- Started from the Band Ninja Dojo (Arcade tab), the score is turned in to Band Ninja. Opened on its own it is a practice test and nothing is saved.

## v1.1.0 — 2026-11-19
- Opening from the Band Ninja Dojo picks your instrument automatically (link ends in ?inst=…). You can still change it.

## v1.0.0 — 2026-11-19
- First release: Key Signature Trainer for Raven Band.
- Four modes: Key Signature Notes, Accidentals, Put It Together, Find Them All.
- Every instrument sees its own written key (B♭, E♭, F horn transpositions); treble and bass clef.
- Beginner concert keys: B♭, E♭, F, A♭, C (choose in Settings).
- Wrong answers explain why (key signature in every octave, accidental carries to the barline, natural cancels, barline resets, courtesy accidentals).
- Class display for the viewboard: bigger staff and buttons, Reveal button (R), "Rotate through all instruments".
- Light/dark theme; keyboard shortcuts (A–G, 1 ♭ / 2 ♮ / 3 ♯, Enter, Esc).
